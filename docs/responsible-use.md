# Responsible Use

NanoJuris foi desenhado para extracao responsavel de jurisprudencia publica.

## Regras

- Nao burlar captcha.
- Nao automatizar login.
- Nao acessar conteudo restrito.
- Nao coletar dados em volume agressivo.
- Nao remover contexto de fonte.
- Nao prometer completude.

## Erros esperados

Providers devem retornar erros claros quando houver:

- fonte fora do ar;
- rate limit;
- controle de acesso;
- mudanca de contrato;
- resposta invalida.

## Agentes de IA

Agentes devem usar o NanoJuris como camada de consulta e recuperacao de fontes.
A interpretacao juridica deve ser revisada por profissional habilitado.
